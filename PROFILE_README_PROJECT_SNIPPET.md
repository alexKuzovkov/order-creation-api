### [order-creation-api](https://github.com/alexKuzovkov/order-creation-api)

**Production-oriented .NET 9 API** focused on safe resource creation and idempotency.

- Policy-based authorization
- Concurrent-safe idempotent creation
- Conflict detection for reused idempotency keys
- Explicit `OrderState`
- Domain invariants and trading-rule validation
- Problem Details error handling
- User-isolated resource lookup
- Docker + GitHub Actions E2E

`C#` · `.NET 9` · `ASP.NET Core` · `REST` · `Idempotency` · `Docker` · `xUnit`
